Scratch 学完之后学什么？图形化到 Python 的衔接节点

Scratch“学完”不是认全积木块，而是能独立做出一个完整项目。转 Python 前要先补三块：变量思维、读文本代码的习惯、项目拆解能力。

结论先行：Scratch 学完不等于可以直接打开 Python 编辑器。真正的衔接节点是能独立完成一个完整项目（大约 20 块以上积木、有变量和条件判断），并且能说清“这段代码在干什么”。达到这一步，通常 9–10 岁左右，转 Python 才顺。

一、Scratch 学“完”的标志是什么

不是把所有积木块都点过一遍，而是这三件事能做到：

  • 能自己拆任务。给一个题目（比如“做一个计分的小游戏”），能拆成角色、背景、得分、结束条件几块。
  • 会用变量。知道“分数”要存在变量里，而不是复制粘贴一堆数字。
  • 能调试。程序不对，会自己加一个“说一句话”来检查中间结果，而不是全部重做。

二、转 Python 前要补的三块

  1. 变量与数据类型。Scratch 里变量是拖出来的，Python 里要先想“这是数字还是文字”。这一步不过关，后面全是错。
  2. 读文本代码的习惯。图形化是“看形状”，代码是“读句子”。要能一行一行读下来，知道缩进代表层级。
  3. 项目拆解能力。Python 没有积木块提示，得先想清结构再写。这一步最好在 Scratch 阶段就练好。

三、可以开始转的五个信号

  1. 能独立做出一个带计分/计时的小游戏，不需要老师逐句指导。
  2. 知道“变量”是什么，能说出“为什么要用它”。
  3. 能读懂简单的英文单词（print、if、for 这类）。
  4. 出错时不慌，会主动说“我想加个输出看看”。
  5. 能坐住 30 分钟以上做同一件事。

五条里满足三条，就可以开始接触文本代码；只满足一两条，建议继续在图形化里做更复杂的项目。

四、直接跳 Python 的三个坑

  • 语法错误压过逻辑思考。孩子把时间全花在“少了一个冒号”上，反而没练到真正的思维。
  • 没有作品，失去动力。图形化一节课能出动画，代码课前三节可能只输出一行字，落差很大。
  • 退回“抄代码”。照抄能跑，但一改就崩——这是最常见的假学会。

五、乐之疆的衔接安排

我们的路线是：7 岁起进 Scratch 图形化编程，把事件、循环、变量、条件判断打牢；到进阶阶段转 Python 代码编程，从变量、数据类型、判断与循环起步，做 2D 小游戏与小工具，再衔接人工智能入门。中间不会硬跳——老师会先看孩子能不能独立完成项目，再决定什么时候转。

课时口径：小学三年级以下 60 分钟／次，三年级以上 120 分钟／次，一周 1 次，2–4 人小班；器材由校区提供。

六、卡在 Scratch 很久了怎么办

常见原因是“一直在做同类项目”——每次都是小猫走路、打地鼠，难度不涨。解法是换题型：加变量（计分）、加条件（结束判定）、加多角色协作。这三样一加，Scratch 的天花板会明显抬高，也为转代码做了准备。

七、下一步

想判断孩子现在该不该转，最直接的办法是带他现在的作品来——老师看项目复杂度，比看学了几年准得多。
